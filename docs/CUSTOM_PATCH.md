# 个人定制分支（0.3.0）

官方基线为 `0.3.0`（`c24e17eec3af1e6dedfa9935a6d15245cf2f4586`）。`master` 保持官方代码；
`custom/ui-only` 用于个人定制。2026-10-16 的迁移保留旧分支的提交历史，不重写或覆盖 0.2.6 的修改。

## 保留的功能

- 本局信息按受影响盟约分行显示干员头像：彩色可用、灰色禁用，悬停显示姓名和状态；保留原有盟约图标及禁用提示。
- 同盟首领战结算显示 `战前个人生命(结算全队生命/战前全队生命)`，历史记录保留对应快照；单人及缺少快照的旧记录保持原有显示。
- 结算与对局记录共用阵容展示，干员头像下显示携带装备的小图标，保留装备顺序和重复装备。
- 存活至最后的玩家，在完整生命数值前也显示目标生命图标；提前结束的玩家和旧记录保持原有图标。
- 选择模拟难度的界面显示同服房间：房主、模式、人数、准备／游戏状态，以及加入和观战入口。只有观战可中途加入。
- 房主可在准备室勾选准备阶段计时器；打开时单人也倒计时，关闭时多人也不限时。选卡、机变和战斗计时不受影响。
- 重进对局后，渲染模块延迟加载导致的普通棋盘会有次数限制地自动恢复；保留手动简化渲染和 2D 偏好。

## 0.3.0 适配

- 准备计时器同时传给玩法插件的独立对局进程，不丢失 `true` 或 `false`；不改插件权限、内容校验或同意流程。
- 大厅在选择插件自定义模式时显示该模式名和「非官方」标记，不披露内容哈希、插件设置、玩家 ID 或令牌。
- 重进测试采用新版正常的「恢复对局」入口；仅 macOS 使用 Metal 测试后端。
- 包含独立的跨平台测试兼容性修复（上游 PR #674）；Windows + Node 22 的完整 CI 分成两批，各保留 25 分钟时限。

装备库存及五阿戈尔联防复活采用官方 0.3.0 实现，不恢复旧版自行修改的战斗规则。未修改官方数据或模拟代码。

旧版来源：原 `ui-only-v026-20261013` 界面补丁及本仓库 PR #1–#5。其 0.2.6 历史记录保留在 `docs/history/0.2.6.md`。
升级时应使用定制分支代码，不要用官方完整包覆盖定制版。游戏素材、运行依赖、令牌和服务器备份不提交到 Git。
