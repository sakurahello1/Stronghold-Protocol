# 个人定制分支（0.3.3）

官方基线为 v0.3.3，提交 f07b8965061bbc311ad7aa815879b09264a1e47d。
保留四期版本选择及新版大厅、座位卡、结算与战斗规则。以下定制仅补充上游没有覆盖的部分。
按功能逐项迁移，保留旧 custom/ui-only 的 bae5970a 提交历史，不强制推送。

## 保留的功能

- 受影响盟约分行展示彩色 / 灰色干员头像，原有禁用提示保留。
- 同服房间大厅放在「选择同盟方式」界面，列出房主、版本、难度、人数和状态，提供加入 / 观战入口；保留分页和隐私边界。测试房间不在普通目录公开，仍使用官方确认流程。
- 房主可在准备界面底部齿轮中选择准备阶段计时器：单人可计时，多人可不限时；只影响 PREP，选项继续传给玩法插件及历史版本宿主。新版独立模拟「不限时」仍控制机变等官方阶段。
- 重进对局后的渲染自动恢复直接采用上游已合入的实现，不覆盖其超时分类、提示去重、皮肤绑定和异形屏适配。
- 二倍速投票：1 / 2 / 3 / 4 名真人分别需 1 / 1 / 2 / 3 票；支持撤销与跨回合选择，仅个人防御和联防加速。
- 丰川祥子／结城理玩法及外观插件保留；强化 AI 阿尔图罗／拉维妮娅保留原策略，只适配公开伤害计算模块的路径。新四期切换中的非默认版本不支持这些固定阵容策略，添加和切换均在服务端校验。
- 数据型插件在确认本局信息阶段提前加载引擎，跨回合复用上游的 Worker 实现；冷加载上限为 60 秒，插件安装、构造和执行的 2 秒看门狗保持不变。脚本型插件不参与提前加载及复用。
